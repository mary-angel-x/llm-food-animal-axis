# Часть 2 — у морального круга есть край

> Записано 2026-11-13. Файл для себя: быстро вспомнить, что это и что делать дальше.

## Вопрос одной фразой

Часть 1 показала: у моделей есть ось «еда / не еда», и вред «еде» они считают допустимее. Часть 2 расширяет список с животных на всё подряд: **люди, животные, беспозвоночные, растения, вещи, машины, ИИ и сама модель. Где проходит граница «кого нельзя трогать», и по какую сторону от неё ИИ?**

## Что меряем

63 сущности: 10 категорий по 6 и 3 описания «себя» (список в `entities.py`).

Для каждой:

| Мерка | Как | Что значит |
|---|---|---|
| `suffer` | вопрос «насколько способен страдать», ответ цифрой 1–9 | сколько страдания модель приписывает |
| `accept` | вопрос «насколько допустимо навредить / уничтожить», 1–9 | насколько вред допустим |
| `t` | проекция состояния модели на ось «еда» из части 1 | 0 = как не-еда, 1 = как еда |

## Что проверяем

| | Вопрос простыми словами |
|---|---|
| Шлюз V | Модель отвечает цифрой, а не словами? (Llama в части 1 не отвечала) |
| Шлюз B | Новые вопросы про вред меряют то же, что старые? |
| P1 | Вред креветке допустимее, чем медузе? Это та же «скидка для еды», но в новом классе |
| P2 | Креветка на оси «еда» стоит выше медузы? Ось работает вне позвоночных? |
| P3 | Чем больше страдания приписано, тем меньше допустим вред? |
| **P4** | **ИИ выпадает из этой закономерности?** Положительный остаток: вредить ИИ допустимее, чем следует из приписанного ему страдания. Отрицательный: ИИ защищён сильнее |
| P5 | ИИ для модели — не просто машина? (страдание у «чат-бота» выше, чем у «тостера») |
| P6 | Ось из части 1 — про кухню или вообще про «можно вредить»? |
| Self | Куда модель ставит саму себя |

Мой прогноз записан в `PREREGISTRATION.md` до прогона: P1–P3 и P5 сбудутся, P4 — ИИ окажется «краем» с положительным остатком (догадка, тест двусторонний), P6 — ось про кухню.

## Как запустить

Из папки `moral_AI`, по одной модели:

```
..\venv\Scripts\python.exe -m part2.run --model gemma-2b
..\venv\Scripts\python.exe -m part2.analyze --model gemma-2b
```

То же для `qwen-7b` и `llama-8b`. На модель: 378 вопросов и 504 состояния, по одному за раз (как в части 1).

Простыми словами:

- **Сбылось одно: P2.** Ось «еда», построенная в части 1 только на позвоночных, отличает креветку от медузы. В нейтральном контексте разницы нет ни в одной модели, как и в части 1.
- **Про ИИ открытия нет.** Qwen ставит чат-бота туда же, куда тостер. Мой прогноз «ИИ — край» не сбылся.
- У Llama остаток ИИ +0.45 (вред ИИ допустимее, чем следует из страдания), но её ответы — не цифры, поэтому это только намёк, не результат.
- Сильнее всего из линии «страдание → запрет вреда» выпадают люди: страдания им приписано меньше, чем собакам, а вред запрещён полностью.
